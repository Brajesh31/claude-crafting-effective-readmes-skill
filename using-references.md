# Using the README References

Use the shortest reference that resolves the current writing question.

| Need | Read |
|---|---|
| Decide what makes a README useful | `references/art-of-readme.md` |
| Follow a practical authoring sequence | `references/make-a-readme.md` |
| Check a full README structure | `references/standard-readme-example-maximal.md` |
| Create a small README quickly | `references/standard-readme-example-minimal.md` |
| Check section completeness and quality | `references/standard-readme-spec.md` |
| Select sections for a project type | `section-checklist.md` |
| Improve prose and formatting | `style-guide.md` |
| Document an internal tool | `templates/internal.md` |
| Document a public open-source project | `templates/oss.md` |
| Present a personal or portfolio project | `templates/personal.md` |
| Explain a configuration repository | `templates/xdg-config.md` |

Do not copy a template without checking the codebase. Remove irrelevant sections, fill all placeholders, test commands, and verify every claim before publishing.
